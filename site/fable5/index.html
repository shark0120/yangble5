Fable5:先跑完流程,才准出貨。

Fable5 是一個給 Claude Code 與 Codex 用的 skill:它讓 agent 不再「答一次就交卷」,而是走一條固定的執行迴圈,最後過一道評分閘門才能出貨。 每一條結論都必須標上四態之一:VERIFIED / SUPPORTED / UNVERIFIED / CONTESTED。 閘門不過就升深度重跑;全部腳本離線執行,不連網、不需要任何 API 金鑰。

BOOT > ORIENT > DECOMPOSE > EXECUTE > VERIFY > REDTEAM > CRITIC~EXECUTE > SYNTHESIZE > METACRITIC > GATE > (BUMP | OMEGA | SHIP)
  • 它不是模型,也不呼叫任何模型
  • 評分是結構性檢查,PASS 不代表內容為真
  • 不連網、不回報、不收集任何資料

下載與核對

先對雜湊,再解壓

fable5-v1.0.0.tar.gz

對應的公告摘要:fable5-v1.0.0.tar.gz.sha256

SHA256(全文,逐字比對):
ee1473e759506e5e7a307c221c0521dfe5fa3288b1e9c52c87bbfdb315c6b796

摘要跟壓縮檔在同一個網域。這能擋下載壞掉或被攔截的情況,擋不了來源本身被換掉 —— 所以只從 yangble5.com 下載,別的地方給你的檔案一律不要信。

安裝

四步:下載 → 核對 → 解壓 → 自測

  1. 下載上面兩個檔案到同一個資料夾。
  2. 核對 SHA256。不符就停,不要解壓。 
    # macOS / Linux
shasum -a 256 -c fable5-v1.0.0.tar.gz.sha256

# Windows PowerShell:算出來的值必須等於 .sha256 檔裡那一行
Get-FileHash .\fable5-v1.0.0.tar.gz -Algorithm SHA256
  3. 解壓到 skills 目錄。壓縮檔內是一個頂層 fable5/ 資料夾。 
    # Claude Code
tar -xzf fable5-v1.0.0.tar.gz -C ~/.claude/skills/

# Codex
tar -xzf fable5-v1.0.0.tar.gz -C ~/.codex/skills/
  4. 跑 selftest。離線執行,看到 fable5_selftest: PASS 才算裝好。 
    cd ~/.claude/skills/fable5/scripts
python fable5_selftest.py

誠實限制

評分腳本只檢查報告的結構、標籤與證據格式 —— 它無法判斷內容是否為真, 一份格式漂亮但結論錯誤的報告一樣能過閘門。把 PASS 讀成「流程有走完」,不要讀成「答案是對的」。

要讓 AI agent 代為安裝?給它 FABLE5.md —— 那份文件會要求它下載、核對雜湊、先列出壓縮檔內容給你看、問過你才安裝。
